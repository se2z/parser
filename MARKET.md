# Мониторинг встроенного маркета Telegram

Источник `SOURCE=telegram` использует официальный MTProto API и пользовательский аккаунт. Telegram-бот по BOT_TOKEN только управляет доступом и отправляет сообщения. Это мониторинг встроенной перепродажи коллекционных подарков Telegram, не Fragment, Portals или сторонних сайтов.

## Вход из админ-панели

Рекомендуемый вариант: запустите бот без сессии и откройте **/admin → Подключить аккаунт → Открыть форму входа**. В браузере на этом же компьютере введите номер, код и пароль 2FA при необходимости. Без QR. Подробности — [ADMIN.md](ADMIN.md). API ID/hash задаются заранее в .env. Описанный ниже login-market.bat остаётся альтернативой при остановленном боте.

## Подключение через консоль

1. Выполните `install.bat` (или `npm ci`) один раз. Зависимости закреплены в package-lock.json: @mtcute/node 0.32.8, long 5.3.2.
2. Создайте `.env` из `.env.example`. Получите API ID и API hash для своего приложения на https://my.telegram.org/apps. Запишите их в `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
3. Укажите `SOURCE=telegram`. Запустите **login-market.bat**. Введите номер, код из Telegram и пароль 2FA, если потребуется, только в локальной консоли. При вводе пароль может быть виден на экране. Не присылайте код или пароль в чат.
4. Сессия сохраняется в `data/market.session` и сопутствующих файлах. Они дают доступ к аккаунту: не публикуйте и не передавайте их. `.gitignore` исключает data и *.session*.
5. Заполните `BOT_TOKEN`, `ADMIN_IDS`, `GROUP_ID` и ID тем в config.json по README. Для темы TON можно указать тот же threadId, что для «Парс», либо отдельный. Карточки в Stars распределяются по диапазонам XTR, карточки только в TON — по диапазонам TON.
6. Запустите **start-bot.bat**. Не запускайте login-market.bat одновременно с работающим ботом на одной сессии.

Само приложение не покупает, не переводит и не выставляет подарки: адаптер вызывает только методы чтения. Реальная авторизация и чтение маркета требуют ваших локальных настроек; автоматические тесты используют подставные ответы API.

## Как обнаруживаются лоты

- `payments.getStarGifts` возвращает каталог типов подарков. Берутся типы с доступной перепродажей; каталог кэшируется до часа, чтобы не расходовать запросы при каждом обходе.
- `payments.getResaleStarGifts` читает продажи по конкретному base gift ID. Сортировка по цене и номеру выключена: Telegram сортирует по времени последнего изменения цены, начиная с новых.
- Обрабатываются страницы `nextOffset`, до пересечения с известными лотами или лимита MARKET_MAX_PAGES. Один цикл последовательно обрабатывает все коллекции. Объявления передаются боту сразу после обработки каждой коллекции. Проверяются свежие страницы продаж, а не каждый существующий NFT отдельно.
- Первый обход каждой коллекции — базовый снимок без публикации старых лотов. Чтобы опубликовать и текущие объявления при первом обходе, поставьте `MARKET_PUBLISH_EXISTING=true` до него. Уже сохранённый baseline эта настройка не сбрасывает.
- Новый slug или изменившаяся комбинация владельца/цен создаёт событие. Увиденные данные сохраняются в SQLite. Изменение цены тоже может появиться как новая карточка: API не даёт отдельную гарантированную ленту событий «только что выставлено». Неотличимое повторное выставление с прежними владельцем и ценой не создаёт новую карточку.
- Перед бронью `payments.getUniqueStarGift` повторно проверяет продажу и цену. Если данные поменялись, бронь отклоняется. Между проверкой и внешней покупкой лот может купить другой человек: внутренняя бронь его на маркете не блокирует.

Из ответа берутся название, номер, slug, модель, реальная цена и публичный владелец, если раскрыт. Premium берётся только из возвращённого объекта User. Уровень и цена сообщения пока не запрашиваются и не выдумываются. Изображение показывается Telegram как превью ссылки `https://t.me/nft/<slug>`, если такое превью доступно. Отдельная ссылка «Оффер (-2%)» из MTProto-ответа автоматически не генерируется.

## Настройки .env

```dotenv
SOURCE=telegram
TELEGRAM_API_ID=
TELEGRAM_API_HASH=
TELEGRAM_SESSION_PATH=data/market.session
POLL_SECONDS=5
MARKET_GIFT_IDS=
MARKET_PAGE_SIZE=100
MARKET_MAX_PAGES=3
MARKET_REQUEST_DELAY_MS=1000
MARKET_PUBLISH_EXISTING=false
```

Пустой MARKET_GIFT_IDS означает все коллекции с перепродажей. Можно указать через запятую ID базовых подарков (64-битные значения хранятся строками, не номера вроде #105623). Целевой интервал между началами обходов — 5 секунд. Если обход завершился быстрее, планировщик ждёт остаток интервала; если дольше — начинает следующий после завершения. Параллельные обходы и очередь пропущенных запусков не создаются. Журнал показывает число обработанных коллекций, длительность и превышение интервала. Пять секунд — целевой интервал, а не подтверждённая скорость полного обхода рынка.

Telegram не публикует универсальный безопасный лимит запросов для этого метода. На FLOOD_WAIT адаптер выдерживает указанную паузу; не обходите её несколькими сессиями. Если поток новых лотов превысит глубину страниц или лот выставят и снимут между опросами, он может быть пропущен. При достижении лимита страниц журнал показывает предупреждение. Гарантии мгновенного или полного перехвата нет.

Опрос идёт отдельно от обработки Bot API, чтобы страницы маркета не останавливали кнопки и контроль подписок. `/admin pause` и `/admin resume` управляют опросом. Данные `market_seen` и `market_baseline` сохраняются в той же БД; перезапуск их не сбрасывает. Установите актуальные ID тем до запуска: нераспределённые по фильтрам цены не публикуются.

## Проверка

`npm test` проверяет базовый снимок, новые объявления, изменения цены, дедупликацию после пересоздания адаптера, пагинацию, FLOOD_WAIT, Stars/TON, скрытого владельца и повторную проверку перед бронью. Проверка подключения к реальному аккаунту выполняется локально после login-market.bat.

Официальные источники, проверены 17.11.2026:

- [Перепродажа подарков](https://core.telegram.org/method/payments.getResaleStarGifts) — доступно только пользователям.
- [Коллекционный подарок](https://core.telegram.org/constructor/starGiftUnique) — поля владельца, slug и цены.
- [Работа с подарками](https://core.telegram.org/api/gifts) — порядок сортировки и пагинация.
- [mtcute](https://github.com/mtcute/mtcute) — используемый MTProto-клиент.
