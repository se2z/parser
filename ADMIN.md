# Админ-панель

Если Telegram Desktop работает, а бот не отвечает: Node.js может не использовать прокси VPN автоматически. Для Bot API укажите HTTPS_PROXY (например, локальный HTTP-порт вашего VPN), для чтения маркета — TELEGRAM_PROXY_URL (HTTP или SOCKS). Запускайте обновлённый start-bot.bat: он включает --use-env-proxy. В этой установке проверен локальный Xray http://127.0.0.1:10809; он должен работать во время запуска бота. Подключение аккаунта и создание тем выполняются в фоне и больше не блокируют меню.

Откройте личный чат бота и нажмите **⚙️ Админ-панель** в постоянной клавиатуре под полем ввода. После обновления бота нажмите «Начать» или отправьте `/start`, чтобы получить кнопки. Вводить команду для открытия панели не требуется. Панель доступна только ID из `ADMIN_IDS` в `.env`; список изменяется владельцем проекта в файле, не обычными пользователями бота. После изменения ADMIN_IDS перезапустите бот.

## Подключение аккаунта без QR

1. В `.env` задайте `SOURCE=telegram`, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` (с https://my.telegram.org/apps).
2. Запустите start-bot.bat. Сессия пока не обязательна: бот продолжит работать и покажет статус «Аккаунт не подключён».
3. В админ-панели нажмите **📱 Подключить аккаунт → Открыть форму входа**.
4. Откройте ссылку в браузере **на том компьютере, где работает бот**. Введите номер с + и кодом страны, затем код входа. Если включена двухэтапная защита — введите пароль 2FA.
5. После успешного входа мониторинг получает сессию сразу, без перезапуска. Она хранится локально по TELEGRAM_SESSION_PATH и восстанавливается при следующем старте.

Номер, код и пароль вводятся в локальной форме, а не сообщениями боту. Telegram автоматически аннулирует коды входа, отправленные в другие чаты, даже обычным текстом: https://core.telegram.org/api/auth#invalidating-login-codes. QR не используется.

Форма слушает только `127.0.0.1`, по умолчанию порт `8765` (настройка ADMIN_LOGIN_PORT). Это не опубликованный сайт: с телефона или другого компьютера такая ссылка не подключится к вашему ПК. Для локального входа можно использовать прежний login-market.bat — также номер, код и 2FA, без QR; основной бот перед этим надо остановить.

Ссылка из панели персональная, действует пять минут, содержит случайный токен во фрагменте URL. Форма убирает его из адресной строки после открытия, использует его для авторизованных локальных запросов, не загружает внешние ресурсы и не записывает код или пароль в БД бота. Номер и хеш отправленного кода удерживаются в памяти процесса на время входа. После пяти ошибок или истечения времени нужно начать заново. Бот не регистрирует новые аккаунты и не обходит ограничения FLOOD_WAIT, требование подтверждения email или ограничения доставки кодов Telegram.

Не пересылайте ссылку входа. Подключать аккаунт может один администратор за раз; чужой незавершённый вход не подменяется. **🔌 Отключить** с подтверждением завершает авторизацию Telegram через logOut и останавливает чтение маркета до нового подключения. Это не удаляет аккаунт Telegram.

## Управление доступом

При запуске бот сам создаёт недостающие включённые темы и сохраняет ID. Нажимать кнопки для первичной настройки не требуется. При ошибке прав бот продолжает работу и повторяет попытку не раньше чем через минуту, учитывая retry_after. Кнопки **📂 Темы группы → Создать недостающие темы** оставлены для ручного повторного запуска. В группе должны быть включены темы, а у бота — право «Управление темами». Для готовых тем используйте «Указать ID»; ввод `2 0` отключает вторую строку. Пока включённые темы не настроены, бот работает, панель доступна, а опрос маркета приостановлен без потери базового снимка.

- **👑 Выдать VIP** / **💳 Выдать обычный** — введите `ID ДНИ`, например `123456789 30`. Пользователь должен предварительно нажать /start у бота. Получателю отправляется персональный ключ. Срок начинается при первом вводе ключа, повторный ввод не добавляет дни. Подробности — LICENSES.md.
- **🚫 Отозвать доступ** — введите ID и подтвердите отзыв кнопкой. Исключение из группы выполняет очередь бота.
- **👤 Проверить доступ** — введите ID для просмотра тарифа и срока.
- **🔑 Создать код** — введите `ТАРИФ МИНУТЫ ЧАСЫ_ДЕЙСТВИЯ АКТИВАЦИИ`, например `vip 1440 24 10`. Подходит для ключей и промокодов. Один пользователь может активировать код один раз.
- **💰 Тарифы и кулдауны** — введите `ТАРИФ ЦЕНА_STARS ДНИ КУЛДАУН_СЕК`, например `vip 500 30 5`. Изменения сохраняются в config.json. Уже созданные счета сохраняют прежние цену и длительность; новая настройка кулдауна применяется сразу.
- **⏸ Пауза / ▶️ Продолжить** — управление мониторингом. Если сессии нет, нажатие «Продолжить» не создаёт авторизацию.
- **📊 Статистика** — пользователи, лоты и ошибки очереди.
- **🔄 Обновить настройки** — перечитать config.json после ручного изменения тем и фильтров.

`/cancel` отменяет незавершённый ввод. Диалоги выдачи доступа, подтверждения и подключения истекают через пять минут. Проверка ID администратора выполняется для каждого действия; кнопка, пересланная постороннему пользователю, не даёт прав.

Текстовые сообщения администраторов в личном чате намеренно не сохраняются в журнале входящих обновлений (inbox), чтобы случайно присланные секреты не попадали в SQLite. После сбоя незавершённый ввод необходимо повторить. Платёжные события сохраняются для восстановления оплаты.

Рабочая авторизация через настоящий аккаунт проверяется после настройки ваших API-реквизитов. Автотесты проверяют вход и 2FA на mock-клиенте, изоляцию администраторов, сроки входа, отключение, выдачу VIP, подтверждение отзыва, изменение тарифов, права и авторизацию локальной формы.
